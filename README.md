# newqr

Generador de códigos QR desde la terminal.

## Instalación

```bash
npm install -g newqr
```

## Uso

```bash
newqr
```

O sin instalar:

```bash
npx newqr
```

Selecciona el tipo de QR, introduce los datos y elige el formato de salida (PNG, SVG o portapapeles).

## Tipos de QR soportados

- Texto plano
- URL
- WiFi
- Contacto (vCard)
- Email
- SMS
- Teléfono
- Ubicación (GPS)
- Evento de calendario

## Requisitos

- Node.js >= 18
